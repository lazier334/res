安装指南 ​

本指南将帮助你安装和配置 LazierServer。

系统要求 ​

nodejs版本 ​

  • Node.js: >= 24.0.0
  • npm: >= 11.0.0
  • 操作系统: Windows, macOS, Linux

安装方式 ​

方式1: npm全局安装（推荐） ​

bash
# 全局安装
npm i -g lazierserver

# 验证安装
ls334 --version

方式2: 本地安装 ​

bash
# 创建项目目录
mkdir my-server
cd my-server

# 初始化项目
npm init -y

# 安装依赖
npm i lazierserver

# 启动服务器
npx ls334

方式3: Docker安装 ​

bash
# 拉取镜像
docker pull ghcr.io/lazier334/lazierserver:latest

# 运行容器
docker run -d -p 3000:3000 -p 3001:3001 lazierserver

(可选) 自定义配置HTTPS证书 ​

方案一: 在配置文件 conf.js 中添加证书 ​

javascript
export default {
    SSLOptions: {
        key: `-----BEGIN PRIVATE KEY-----
        你的私钥内容
        -----END PRIVATE KEY-----`,
        cert: `-----BEGIN CERTIFICATE-----
        你的证书内容
        -----END CERTIFICATE-----`
    }
}

方案二: 写一个 systemStart 阶段的插件进行修改 ​

js
// systemStart-1-setSSL.js
import { createSystemStart } from 'lazierserver/types';

export default createSystemStart(async function systemStartCommon({ fs, path, config, app }) {
    config.SSLOptions.key = `-----BEGIN PRIVATE KEY-----
        你的私钥内容
        -----END PRIVATE KEY-----`;
    config.SSLOptions.cert = `-----BEGIN CERTIFICATE-----
        你的证书内容
        -----END CERTIFICATE-----`;
})

启动服务器 ​

基本启动 ​

bash
# 在项目目录启动
ls334

# 或使用npm脚本
npm start

指定端口启动 ​

bash
# 使用8080端口
ls334 --port 8080

# 或简写
ls334 -p 8080

验证安装 ​

1. 访问Web界面 ​

打开浏览器访问：

  • HTTP: http://localhost:3000
  • HTTPS: https://localhost:3001

2. 测试API接口 ​

bash
# 测试系统接口
curl http://localhost:3000/system/version

# 测试配置接口
curl http://localhost:3000/system/config

3. 检查日志 ​

查看服务器日志确认启动成功：

bash
# 查看日志目录
ls ld/logs/

# 查看实时日志
tail -f ld/logs/info-*.log

常见安装问题 ​

问题1: Node.js版本过低 ​

因为部分代码使用最新的写法，例如 import.meta.dirname ，在旧版本的nodejs中不支持，所以会导致有奇怪的异常。

错误信息:

TypeError [ERR_INVALID_ARG_TYPE]: The "path" argument must be of type string. Received undefined
Error: Node.js version 18.x is not supported. Please upgrade to Node.js 24.0.0 or higher.

解决方案:

bash
# 使用nvm切换Node.js版本
nvm install 24
nvm use 24

# 或升级Node.js
# 访问 https://nodejs.org 下载最新版本

问题2: 端口被占用 ​

错误信息:

Error: listen EADDRINUSE: address already in use :::3000

解决方案:

bash
# 查找占用端口的进程
lsof -i :3000

# 终止进程
kill -9 <PID>

# 或使用其他端口
ls334 -p 8080
